# File Operations

这个技能提供常用的文件和目录操作功能。

## 功能

- 创建文件和目录
- 删除文件和目录
- 移动和重命名文件
- 读取文件内容
- 写入文件内容
- 列出目录内容
- 查找文件

## 使用场景

当你需要执行文件系统操作时，可以使用这个技能。例如：
- 创建新的项目目录结构
- 清理临时文件
- 批量重命名文件
- 查找特定文件
